Listening to Sanskrit, and watching long videos for you

Three working systems built from first principles: Sanskrit pronunciation comparison with MFCC and spectral features, verse recognition with hidden Markov models, and a pipeline that turns a long video into key frames, scenes, motion maps, tracks and a short summary. Everything runs in your browser, so recordings and videos never leave your device.

How it is built

  • Plain HTML, CSS and JavaScript modules with no build step. FFT, mel filterbank, MFCC, YIN pitch, DTW, Gaussian HMM (Viterbi and Baum–Welch), LDA and all the video processing are written from scratch.
  • The only third-party model is COCO-SSD (TensorFlow.js), loaded on demand for person detection.
  • The same DSP and HMM modules run in Node for offline training (scripts/train_gita_hmm.mjs) and in the browser for inference and retraining.
  • The speech corpus (372 clips) was synthesised with six neural TTS voices in Hindi, Marathi and Nepali. The demo video is procedurally rendered with OpenCV and comes with ground-truth scene boundaries.

Reproduce

pip install edge-tts opencv-python numpy imageio-ffmpeg
python scripts/generate_audio.py      # speech corpus
python scripts/make_demo_video.py     # demo video + ground truth
export FFMPEG=$(python -c "import imageio_ffmpeg as f; print(f.get_ffmpeg_exe())")
node scripts/train_gita_hmm.mjs       # verse HMMs + evaluation
node scripts/train_lda.mjs            # speaker-robust LDA
node scripts/calibrate_pronunciation.mjs
